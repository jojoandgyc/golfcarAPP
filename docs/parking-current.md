# 驻车电流

本车没有独立的电子驻车开关。左、右侧分别以驻车电流决定是否启用：0 A 关闭，正值开启。两侧都是正值才显示整体开启；两侧都是 0 才显示整体关闭；一侧为 0 时分别显示。电流配置不等于车辆已停稳。

App 的手动 → 驻车页在同一页提供左右电流输入、读回值、刷新与保存。输入和加减按钮随时可用，不要求先启用手动控制或点击读取。保存时自动读取当前上限；只修改左 0x0076、右 0x006D，单位为 0.01 A，不修改最大输出电流或其他调好参数。

“设为 0 A”只填写两个输入框，点击保存才发送。输入框是待保存值，显示状态始终来自电流读回，不能通过修改草稿或点击按钮提前改变。断连保留上次读取值并标注非实时。部分写入失败分别保留已核对、未确认和未尝试结果，不自动重试或回滚。

统一驻车接口使用 schemaVersion 2、parkingSemantics `current_zero_disables`。App 只发送 read/currents；旧版用停止模式模拟驻车开关的指令已废弃。普通停车、急停和网络保护仍通过各自原有路径执行，不会自动重写驻车电流。

空闲时使用独立桥接，在手动控制过程中由已有串口 owner 串行处理。设置前清除转速目标；无需等待反馈转速严格为零或 PWM 为零。保留数值编码、设备电流上限及串口互斥检查。
