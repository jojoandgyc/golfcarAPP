# LZ-30EMA 完整 99 接口清单

依据用户 V1.0 手册逐项核对，schemaVersion 2。计数为 69 个配置逻辑字段 + 22 个只读逻辑字段 + 8 个操作接口；双字字段仍算一个逻辑接口。保留地址未列入。

本轮全部实际验证仅使用内存模拟与 Android 模拟器，未部署、未改动实车电机参数。编码与已确认歧义见 [协议审核](motor-configuration-protocol-review.md)，调用格式见 [v2 桥接](motor-configuration-bridge.md)。

## 控制接口（8 项）

控制请求是独立的 `action`，不进入参数批量写入。所有动作都有明确确认；速度／学习采用有界持续时间与收尾，不以命令 ACK 宣称物理完成。

| actionId | 名称 | 地址 | 功能码 | 值／持续时间 |
| --- | --- | --- | --- | --- |
| `right_stop` | 右电机停止 | `0x0040` | FC06 | 0=正常停止, 1=紧急停止, 2=自由停止；0 ms |
| `right_target_speed` | 右 / 直行目标速度 | `0x0041-0x0042` | FC10 | -110000–110000，另受当前速度上限及系统模式限制；100–3000 ms，到时停止 |
| `right_brake` | 右电机抱闸控制 | `0x0043` | FC06 | 0=断开抱闸, 1=闭合抱闸；0 ms |
| `left_stop` | 左电机停止 | `0x0044` | FC06 | 0=正常停止, 1=紧急停止, 2=自由停止；0 ms |
| `left_target_speed` | 左 / 转弯目标速度 | `0x0045-0x0046` | FC10 | -110000–110000，另受当前速度上限及系统模式限制；100–3000 ms，到时停止 |
| `left_brake` | 左电机抱闸控制 | `0x0047` | FC06 | 0=打开抱闸, 1=关闭抱闸；0 ms |
| `factory_reset` | 恢复出厂参数 | `0x0048` | FC06 | 1=恢复出厂；0 ms |
| `phase_learning` | 相序学习 / 取消测试 | `0x0049` | FC06 | 0=取消测试, 1=左电机相序学习, 2=右电机相序学习；学习 100–60000 ms，到时取消，直接取消为 0 ms |

差速模式下左目标是转弯目标，左停止命令无效；有界转弯收尾发送右停止 `0x0040`。同源模式下右目标作用于两侧，左速度／左停止无效。恢复出厂和 RS485 链路参数变更均要求用户重新连接核对。
